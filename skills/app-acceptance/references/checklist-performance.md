# 维度四：性能指标测试清单

> 依据：`rules/CmsPro-v5-应用开发文档.md`（下称"开发文档"）、`rules/CMSPRO-UI开发规范.md`（下称"UI 规范"）、CMSPRO 开发规范
> 检查对象：应用 Models/Services/Controllers 查询逻辑、迁移索引、缓存、前端资源与动效
> 判定级别：**[严重]** 一票否决 / **[强制]** 必须整改 / **[建议]** 优化项

---

## 4.1 数据库查询

| # | 检查项 | 级别 | 检查方法 |
|---|--------|------|----------|
| P1 | 高频查询字段已加索引；联合索引遵循最左前缀原则；无全表扫描查询 | [强制] | 读迁移文件索引定义 + Grep Services/Controllers 中 where/orderBy 涉及字段，与索引比对（CMSPRO 规范·开发文档第七章） |
| P2 | 列表查询分页必加 LIMIT（分页对象含 items + pagination 结构），禁止一次性全量加载 | [强制] | Grep：`->all\(\)`、`->get\(\)` 出现在列表接口上下文时核对是否分页（CMSPRO 规范·开发文档） |
| P3 | 数据回填/批处理使用 `chunkById` 分批，禁止 `all()` 全量加载大表 | [强制] | Grep：`chunkById` 核对迁移回填与批处理逻辑（开发文档第七章） |
| P4 | 无 N+1 查询：循环内不做逐条数据库查询；关联访问使用预加载（with/load）或按需批量查询 | [强制] | [人工] 读 Services 循环体；对列表页开启 Laravel Debugbar 或查日志核对查询次数 |
| P5 | 大数据量处理无 O(n²) 及以上复杂度算法（嵌套循环全量比对等） | [建议] | [人工] 读核心 Service 算法（CMSPRO 规范） |
| P6 | 涉及多表写操作使用 `DB::transaction` 保证一致性 | [强制] | Grep：`transaction` 核对多表写场景（CMSPRO 规范） |
| P7 | 及时释放资源：文件句柄处理完关闭（fclose）、大结果集不长期驻留内存 | [建议] | Grep：`fopen\|fget` 等核对配对释放（CMSPRO 规范） |

## 4.2 缓存与配置

| # | 检查项 | 级别 | 检查方法 |
|---|--------|------|----------|
| P8 | 涉及路由的配置（如 access_mode/access_path）保存后执行 `route:clear` 与 `config:clear` | [强制] | 读 SettingController::update（开发文档12A.5·22.9第2条） |
| P9 | Service 层对配置有缓存时（如 `Cache::remember`），配置保存同步 `Cache::forget` 清除，避免读到旧值 | [强制] | Grep：`Cache::` 核对 remember/forget 配对（开发文档22.9） |
| P10 | ServiceProvider 读取应用配置用 `ConfigItem` 模型直查数据库，不使用 `config()` 函数（可能读到缓存旧值） | [强制] | 读 ServiceProvider 核对（开发文档22.9第4条，仅子域名/配置驱动路由应用适用） |
| P11 | 缓存使用考虑穿透/击穿/雪崩：对不存在的 key 不无限回源、热点 key 有并发控制 | [建议] | [人工] 读缓存使用场景（CMSPRO 规范） |

## 4.3 前端资源加载

| # | 检查项 | 级别 | 检查方法 |
|---|--------|------|----------|
| P12 | 资源完全本地化（与 U20 交叉核对），无网络环境下页面可正常加载 | [严重] | 浏览器开发者工具 Network 面板核对全部请求为本地（UI 规范第七章） |
| P13 | 页面无重复加载同一资源（同一 CSS/JS 多次引入）；公共资源不重复打包进应用 Assets | [建议] | 读视图 head 核对引用去重 |
| P14 | 大文件（图片/字体/第三方库）体积合理，无未压缩的大体积资源进入安装包 | [建议] | LS Assets 目录核对文件大小 |

## 4.4 动效与渲染性能

| # | 检查项 | 级别 | 检查方法 |
|---|--------|------|----------|
| P15 | 禁止 `transition: all`；动效优先 transform/opacity（与 I30/I31 交叉核对） | [强制] | Grep：`transition:\s*all`（UI 规范11.4） |
| P16 | 无常驻无限循环动画（骨架屏除外）、无逐项交错动画长列表 | [强制] | 页面访问观察（UI 规范11.3/11.4） |
| P17 | 移动端固定头部禁用 `backdrop-filter`（创建包含块导致 fixed 定位错乱，兼性能负担） | [强制] | 读移动端断点样式核对 `backdrop-filter: none`（UI 规范13.7，仅前台应用适用） |

## 4.5 运行时指标实测

| # | 检查项 | 级别 | 检查方法 |
|---|--------|------|----------|
| P18 | 核心后台页面（列表/仪表盘）在开发环境加载可感知流畅，无明显长时间白屏（>3s） | [建议] | 浏览器访问 `http://<开发环境地址>/admin/...` 计时观察 |
| P19 | 核心列表接口响应结构含分页字段，翻页请求正常、无超长响应体 | [强制] | 页面操作翻页 + Network 核对响应（CMSPRO 约束·分页对象） |
| P20 | 应用路由注册不拖慢全局请求（ServiceProvider boot 内无重查询、无外部 HTTP 调用阻塞） | [强制] | 读 ServiceProvider boot/register 方法核对（开发文档·性能影响评估） |
| P21 | 定时任务（如注册了 schedule）单次执行耗时可接受，异常时不阻塞调度器 | [建议] | 读 ServiceProvider schedule 定义与任务实现核对 |

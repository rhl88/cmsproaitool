# 数据库变更检查清单

**打印此清单，在每次数据库变更前逐项确认！**

---

## 📋 变更前准备

### 基础信息
- [ ] 变更需求已明确（来自Issue/需求文档）
- [ ] 已理解变更的影响范围（哪些表/字段/功能会受影响）
- [ ] 已评估风险等级（🟢低 / 🟡中 / 🔴高）
- [ ] 已确定执行时间窗口（是否需要停机维护）

### 环境准备
- [ ] 开发环境已就绪
- [ ] 测试环境已就绪
- [ ] 生产环境备份已完成
- [ ] 回滚方案已准备

---

## ✍️ SQL脚本编写检查

### 必备要素
- [ ] SQL文件命名规范：`V{版本号}__{描述}.sql`
- [ ] 包含版本号和日期信息
- [ ] 包含详细的变更描述
- [ ] 标注影响范围（表名、字段名）
- [ ] 标注变更类型（DDL/DML）
- [ ] 包含作者信息

### 代码质量
- [ ] **幂等性**：支持重复执行不报错（使用 IF EXISTS/IF NOT EXISTS）
- [ ] **正向变更语句**完整且正确
- [ ] **回滚方案**已提供（注释或独立文件）
- [ ] **数据验证语句**已包含
- [ ] **字段/表注释**完整
- [ ] 无硬编码的敏感信息
- [ ] SQL语法已在测试环境验证通过

### DDL特定检查
- [ ] 新建表包含基础字段（id, status, create_time, update_time）
- [ ] 主键定义正确
- [ ] 外键关系正确（ON DELETE/UPDATE策略合理）
- [ ] 索引设计合理（不过度索引，遵循最左前缀）
- [ ] 字段类型和长度合适
- [ ] 默认值设置合理
- [ ] 约束条件正确（NOT NULL, UNIQUE, CHECK等）

### DML特定检查
- [ ] WHERE 条件正确（防止误操作，避免全表更新/删除）
- [ ] 使用事务包裹相关操作
- [ ] 批量操作有合理的批次大小限制
- [ ] 数据转换逻辑正确且经过测试
- [ ] 考虑并发安全（锁、隔离级别）

---

## 🧪 测试验证

### 开发环境测试
- [ ] SQL脚本在开发库执行成功
- [ ] 执行结果符合预期
- [ ] 应用程序可正常连接数据库
- [ ] 相关功能模块正常工作
- [ ] 无性能明显下降

### 测试环境验证
- [ ] 在测试环境（数据量接近生产）执行成功
- [ ] 执行时间在可接受范围内
- [ ] 回归测试全部通过
- [ ] 性能测试结果正常
- [ ] 监控指标无异常

### 数据完整性验证
- [ ] 记录数正确（无数据丢失）
- [ ] 字段值正确（类型转换无误）
- [ ] 外键关系完整
- [ ] 索引状态正常
- [ ] 统计信息已更新（ANALYZE）

---

## 🔒 安全审查

### 权限与访问
- [ ] 使用最小权限原则执行
- [ ] 无SQL注入风险
- [ ] 敏感数据已脱敏处理
- [ ] 审计日志已开启

### 风险控制
- [ ] 高风险操作（DROP、大规模UPDATE/DELETE）已代码审查
- [ ] 大表操作已评估锁表时间
- [ ] 有明确的回滚触发条件
- [ ] 应急联系人已通知

---

## 📦 提交前最终检查

### 版本控制
- [ ] SQL脚本文件已添加到Git
- [ ] 提交信息规范：`type(db): V{版本} {描述}`
- [ ] 关联的Issue/Ticket编号已标注
- [ ] 相关代码变更已同步提交

### 文档与沟通
- [ ] 变更说明文档已编写（如需要）
- [ ] 团队成员已知晓此次变更
- [ ] 运维团队已收到部署通知
- [ ] 用户通知已发布（如影响用户功能）

---

## ⚠️ 高风险变更附加检查

以下项目仅针对高风险变更（🔴）：

### 前置条件
- [ ] 已获得技术负责人审批
- [ ] 已制定详细的执行计划（精确到分钟）
- [ ] 所有相关人员已就位待命
- [ ] 回滚演练已完成

### 执行监控
- [ ] 准备实时监控仪表盘
- [ ] 设置关键指标告警阈值
- [ ] 准备手动干预预案
- [ ] 记录执行日志和时间戳

### 执行后验证
- [ ] 应用层健康检查通过
- [ ] 关键业务流程验证完成
- [ ] 用户反馈渠道畅通
- [ ] 性能基线对比正常

---

## 🚨 禁止行为确认

我确认本次变更**未涉及**以下任何禁止行为：

- [ ] ❌ 没有SQL脚本的数据库相关代码提交
- [ ] ❌ 在生产环境直接执行未经验证的SQL
- [ ] ❌ 省略回滚方案
- [ ] ❌ 在业务高峰期执行高风险DDL
- [ ] ❌ DELETE/WHERE 1=1 或无条件UPDATE/DELETE
- [ ] ❌ 跳过测试环境直接上生产
- [ ] ❌ SELECT * 生产查询
- [ ] ❌ 循环中执行单条SQL（未批量处理）
